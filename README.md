# СДВИГ

Игра: https://plairpro.github.io/shift/

Статическая сборка прототипа. Полный исходный проект, модели и тесты — в project-source.zip.

Режимы: против бота, вдвоём на одном экране, онлайн по приглашению (WebRTC).

Модели Quaternius, CC0.


## v0.2

Новый интерфейс: все цели робота сразу на поле с цветовой легендой, красные кольца угроз, предупреждение в предпросмотре, уровни бота (Новичок / Боец / Мастер), подсказка, отмена хода, роботы окрашены в цвета команд со значками ролей, ровная камера со стороны игрока.

## v0.3

Поле 7×7 с обрушаемым центром 3×3. Расстановка «Т»: Таран, Якорь и Магнит в ряд, Прыгун за Якорем на крайней линии. Прыгун ходит и по диагонали, но прыгает только по прямой; толчки и притяжение — только по прямой.
